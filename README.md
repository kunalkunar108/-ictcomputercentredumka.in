# ICT Computer Centre Website

React + Vite website for ICT Computer Centre, Dumka.

## Run locally
1. Install Node.js LTS.
2. Run `npm install`.
3. Run `npm run dev`.
4. Build for production with `npm run build`.

## Before production launch
- Replace the fee placeholders with verified fees for all 13 courses.
- Confirm course durations, eligibility and detailed syllabi.
- Add original institute, classroom, lab and faculty photographs.
- Add the exact certification/affiliation name, issuing body and evidence.
- Confirm current opening hours and phone/WhatsApp number.
- Confirm review excerpts and use the official Google review link.
- Confirm domain ownership and configure it in Vercel.

## Accuracy notes
The website deliberately does not invent course fees, durations, affiliations, placement guarantees or institute photographs. The listed 4.8 rating and 108 review count are based on the information supplied for the project and should be rechecked before launch.
